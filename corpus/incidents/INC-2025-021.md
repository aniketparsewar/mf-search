# INC-2025-021 — File Status 39 on ACCTFILE OPEN, 2025-06-02 (SYNTHETIC)

## Summary
JOBPOST03 failed at 23:05 ET: OPEN of ACCTFILE returned **file
status 39** (file attribute conflict). No postings were applied that
night until the file was redefined.

## Root Cause
The ACCTREC copybook change of 2025-05-30 added the field
**ACCT-OVERDRAFT-LIMIT**, growing the account record from **64 to 69
bytes**. The VSAM cluster for ACCTFILE was never redefined, so the
program's record length no longer matched the file's — the classic
status 39 described in RB-VSAM-STATUS.

## Resolution
ACCTFILE was backed up, the cluster was deleted and redefined with
the 69-byte record length, data was reloaded from the backup, and
JOBPOST03 was restarted from its checkpoint. Counts reconciled.

## Follow-ups
- Copybook changes now require a linked VSAM redefinition task in the
  same change record — a copybook must never change alone.
